# A-gateway Phishing Defender Tool

A tool designed to detect and notify users of phishing attacks across websites, emails, and other platforms. This project contains multiple components to safeguard users against phishing attacks and notify them in real-time.

## Features
- **Browser Extension**: Detect phishing URLs and display real-time alerts.
- **Email Scanner**: Identify suspicious emails and flag phishing attempts.
- **Mobile Notifications**: Deliver phishing alerts to users' mobile phones.
- **Web Dashboard**: Allow users to manage fraud detection settings, review logs, and track real-time notifications.

---

## Project Structure
```
/extension        --> Browser extension for phishing detection.
/backend          --> Server-side logic for email phishing detection.
/dashboard        --> React web-based dashboard for management.
/notifications    --> Mobile app notification integration.
```
